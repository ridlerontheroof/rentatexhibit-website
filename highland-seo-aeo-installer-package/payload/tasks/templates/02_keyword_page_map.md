# Task 02 — Keyword and Page Map

## Mode
Planning only.

## Objective
Create a non-cannibalizing keyword-to-page plan for qualified luxury apartment traffic.

## Dependencies
- Approved baseline audit
- Current URL inventory
- Verified property context

## Required Deliverables
- `reports/keyword-page-map.csv`
- `reports/keyword-page-map.md`

Required CSV columns:
- cluster_id
- primary_query
- intent
- current_url
- proposed_url
- page_type
- action
- secondary_queries
- funnel_stage
- conversion_action
- evidence
- risk
- priority

## Rules
- One primary intent per target page.
- Prefer improving existing authoritative pages.
- New pages require distinct renter utility.
- Reject doorway-page concepts.
- Flag search-volume assumptions unless verified through an approved data source.
- Do not alter code.
