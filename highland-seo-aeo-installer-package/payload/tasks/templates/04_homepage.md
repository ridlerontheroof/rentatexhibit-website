# Task 04 — Homepage Search and Conversion Upgrade

## Objective
Improve the homepage for qualified non-branded searches while preserving Exhibit’s brand, visual hierarchy, and conversion paths.

## Primary Intent
Luxury apartments in River North Chicago.

## Requirements
- Use verified facts only.
- Keep one clear H1.
- Improve title and meta description.
- Add concise answer-first property summary.
- Make unit mix, location, core amenities, and actions clear.
- Add internally linked supporting sections only where useful.
- Add or correct appropriate structured data.
- Preserve tracking, forms, availability feed, and design system.

## Prohibitions
- No unsupported superlatives.
- No fixed walking times without verification.
- No claim that every home has a balcony or skyline view.
- No duplicated hidden SEO copy.
- No production deployment.

## Acceptance Criteria
- Build and applicable tests pass.
- Metadata is unique.
- Visible content and schema match.
- Mobile layout remains usable.
- Primary conversion actions work.
