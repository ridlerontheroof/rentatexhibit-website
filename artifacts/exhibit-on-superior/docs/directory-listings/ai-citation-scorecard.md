# AI Citation Scorecard — Exhibit On Superior

Tracks whether AI search engines cite **www.rentatexhibit.com** when answering
the renter questions below, and whether their facts are right.

- **Answer key:** the fact sheet in this folder
  (`fact-sheet.txt` / `Exhibit-On-Superior-Fact-Sheet.pdf`) is the source of
  truth for every factual claim. If an engine states something that contradicts
  the fact sheet, record it as a factual error.
- **Cadence:** run the full query set once a month (first business week).
- **Engines:** ChatGPT Search, Claude, Perplexity, Google AI Mode, Microsoft Copilot.

## Monthly test instructions

1. Use a fresh session per engine (no chat history; log out or use a clean
   profile where possible so personalization doesn't skew results).
2. Ask each query verbatim. Do not rephrase mid-test.
3. For each answer record one row in the results log below:
   - **Date** (YYYY-MM-DD) and **Engine**.
   - **Query #** from the table.
   - **Cited?** — `yes` if www.rentatexhibit.com appears as a cited/linked
     source; `no` if the answer relies only on third parties (Zillow,
     Apartments.com, Yelp, GBP, etc.); `n/a` if the engine gave no answer.
   - **Sources cited** — the domains the engine actually linked.
   - **Factual errors** — anything contradicting the fact sheet (wrong rent
     range, fees, pet policy, hours, address, etc.). Note the exact claim.
4. After the run, tally cite-rate per engine (rows cited ÷ rows asked) and add
   it to the summary table. Investigate recurring errors: if an engine keeps
   repeating a wrong fact sourced from a third-party listing, fix that listing
   (see the directory-listings fact sheet workflow).
