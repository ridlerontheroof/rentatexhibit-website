## Fixes made in this pass

- **Photo-gallery lightbox is now a real modal dialog** (`PhotoGallery.tsx`):
  `role="dialog"`, `aria-modal="true"`, descriptive `aria-label`; focus moves
  to the Close button on open, Tab/Shift+Tab are trapped inside the dialog,
  navigating photos does not steal focus, and closing restores focus to the
  grid thumbnail that opened it. Prev/next controls already had accessible
  names ("Previous photo" / "Next photo").
- **Focus-trap visibility bug fixed in both lightbox traps**
  (`use-lightbox-shortcut-keys.ts` → shared `tabbableIn()` helper, used by the
  gallery lightbox and `UnitGalleryLightbox`): the hidden "?" shortcuts button
  (`display: none` on coarse-pointer / small viewports) was counted as the
  trap's last focusable, letting a real browser Tab past the visually-last
  control into the page behind the dialog. Verified fixed with a real-browser
  CDP probe: Tab cycles Close → Previous → Next → Zoom → Close indefinitely.
- **Hero carousel has an explicit pause control** (`HeroSlider.tsx`): visible
  Pause/Play toggle (WCAG 2.2.2 Pause, Stop, Hide) with `aria-pressed`,
  in addition to the existing hover/focus pause and reduced-motion handling.
- **In-text links no longer rely on color alone** (axe `link-in-text-block`,
  WCAG 1.4.1): body-copy links across the site (`text-primary hover:underline`)
  are now always underlined (`underline underline-offset-4`), matching the
  knowledge-article convention.

## Verified already correct (no change needed)

- **Iframe titles**: Google Map fallback (`title="Map of Exhibit On Superior"`,
  JS map has `role="application"` + `aria-label`), Matterport tours
  (`title="Virtual Tour of <name>"`), unit video tours
  (`title="Video tour of apartment <unit>"`), community video (video name).
- **Forms** (`ContactUs`, `ScheduleShowing`, `ScheduleTour`): every field has a
  `<label htmlFor>`; errors are specific per field, linked via
  `aria-describedby`, flagged with `aria-invalid`, and announced via
  `role="alert"`; success/failure banners use `role="status"`/`role="alert"`
  and receive focus on submission. Regression-tested in
  `forms-error-a11y.test.tsx` / `forms-thankyou-a11y.test.tsx`.
- **Forms at 200% zoom**: layouts are single-column fluid stacks (max-width
  containers, no fixed heights or horizontal scroll); fields and buttons remain
  fully operable at 200% zoom (equivalent to the 640px-wide small viewport the
  responsive layout already targets).
- **Carousel announcements**: HeroSlider announces slides via a polite live
  region and pauses on hover/focus/reduced-motion.

## Keyboard-only run-throughs (real browser, keyboard input only)

- **Browse → unit → schedule showing**: PASS. Visible focus indicators
  throughout; hero pause button keyboard-operable; unit rows expose descriptive
  link names; unit page → schedule-showing reachable by keyboard; empty submit
  produces per-field errors ("First name is required", "Last name is
  required", "Valid email is required", "Phone number is required") with
  `aria-invalid` + `aria-describedby` wiring.
- **Contact form**: PASS. All fields reachable in logical order with labels;
  empty submit yields specific per-field errors (`firstName-error` …
  `message-error`) wired via `aria-describedby`/`aria-invalid`. (Real
  submissions intentionally not sent — they create real AppFolio leads/emails.)
- **Gallery lightbox**: PASS after the trap fix above — focus contained,
  arrows navigate, Escape closes and returns focus to the opening thumbnail.

## Documented exclusions (axe rules disabled in `check-a11y.mjs`)

- `color-contrast` — out of scope for this pass; the palette was fixed and
  manually verified against WCAG AA in an earlier dedicated contrast task.
  axe's flat-color heuristic still flags the brand-gold accents
  (`.btn-gold-outline`, `text-primary` prices/eyebrows) that were reviewed
  there. If the palette changes, re-enable the rule and re-verify.
- `video-caption` — the Vimeo/YouTube embeds are third-party players; caption
  availability is managed in the video platform, not this codebase.
