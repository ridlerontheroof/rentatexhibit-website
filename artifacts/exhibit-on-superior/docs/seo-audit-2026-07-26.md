## Deferred (with reasons)

- **Trailing-slash 301s** (`/amenities` → `/amenities/` etc.): the static host
  applies a directory-index redirect before rewrites, even though the artifact
  config declares explicit non-slash rewrite pairs for every route. Single-hop
  301 with consistent non-slash canonicals — Google consolidates correctly.
  Not fixable at code level without flipping the entire canonical scheme to
  trailing-slash (high-risk churn across canonicals, sitemap, guards, tests).
  If ad landing URLs are entered with a trailing slash (e.g.
  `https://www.rentatexhibit.com/schedule-a-tour/`), the redirect is avoided
  entirely — recommended for the Ads campaign.
- **Soft 404s** (unknown paths return 200 with the SPA fallback): inherent to
  static SPA hosting; the fallback carries the home canonical so unknown URLs
  consolidate to the homepage rather than index-bloating. `/knowledge/*` has a
  dedicated noindex not-found stub. Low risk; revisit only if GSC reports
  soft-404 growth.
- **No HTML compression, `cache-control: private`, no CSP/X-Frame-Options**:
  headers are set by the platform edge for this deployment type and are not
  configurable from the artifact's static-serve config. Platform-level; note
  for a future platform revisit. HTML payloads are small (~60–90 KB), assets
  are hashed and long-lived.
- **Floor-plan thumbnails `alt=""`**: intentional. The thumbnails sit inside
  buttons whose accessible name is the card's visible text; adding alt would
  break WCAG label-in-name. The full floor-plan images in the lightbox carry
  descriptive alt text.
- **Filter search inputs "unlabeled"**: false positive — both inputs are
  wrapped in `<label>` with an sr-only text span, which is a valid labeling
  technique.
- **Instagram link 429 in link checker**: false positive (Instagram
  rate-limits crawlers).
- **321 KB main bundle / ~13 MB total weight, 24 images >200 KB**: photography-
  heavy pages lazy-load below-fold images; LCP images are preloaded AVIF.
  Bundle held steady through the recent merges; no bloat regression found.
  A per-route bundle budget is a reasonable future guard, not a launch blocker.
- **About page (E-E-A-T)**: new content program — out of scope per task;
  recommended as future content work.
