2. URL and canonical architecture
Standardize every URL variation
The preferred format appears to be:
https://www.rentatexhibit.com/page-name/

Standardize:

HTTP versus HTTPS
www versus non-www
Trailing slash versus no trailing slash
Uppercase versus lowercase
Legacy query parameters
Default document extensions such as .aspx
A test of the non-www homepage indicated a redirect path through an HTTP www address rather than a clean direct hop to the HTTPS canonical. This needs confirmation at the CDN or server-header level.
Target behavior
Every alternate version should redirect directly to:
https://www.rentatexhibit.com/[preferred-path]/

Do not use multiple hops.

Google recommends consolidating duplicate URLs so ranking signals and crawling are concentrated on one preferred URL.

Canonical requirements
Every indexable page should contain:
A self-referencing canonical
The exact preferred HTTPS and www URL
No canonical pointing to a redirected URL
No competing canonical generated by an old platform
Matching Open Graph URL
Matching structured-data URL and @id

Reviews page
Do not expect star snippets from AggregateRating markup on Exhibit’s own website.

Keep the reviews page for trust and conversion. Do not use it as a star-snippet strategy.
