# SEO and AEO Launch Playbook

## Primary search positioning

Use this positioning consistently across page titles, headings, internal links, and local citations:

- Property: Exhibit On Superior
- Manager: Highland Management LLC
- Address: 165 W Superior St, Chicago, IL 60654
- Phone: 312-450-0635
- Email: exhibit@highlandptrs.com
- Core location phrase: River North Chicago apartments
- Unit mix: studio, one, two, and three-bedroom apartments

## What changed in this bundle

- Added unique SEO titles and meta descriptions for every indexable page.
- Added visible Quick Answer sections to help answer engines and featured snippets parse the main fact on each page.
- Added visible FAQ blocks for long-tail renter questions.
- Added JSON-LD files for WebSite, Organization, ApartmentComplex, WebPage, BreadcrumbList, and FAQPage where matching FAQ content exists.
- Added sitemap.xml and robots.txt templates.
- Added SEO/AEO metadata and FAQ CSVs for Webflow, Squarespace, WordPress, or a static host.

## Recommended launch steps

1. Keep the current domain if possible, because retaining the domain reduces migration risk.
2. Submit `sitemap.xml` in Google Search Console after launch.
3. Verify that canonical URLs use the final live domain.
4. Test structured data with Google's Rich Results Test and Schema.org Validator.
5. Update Google Business Profile with the same name, address, phone, website URL, availability URL, photos, hours, and leasing email.
6. Replace old analytics and tag-manager IDs only with Highland-owned IDs.
7. Keep NAP data identical across the website, Google Business Profile, ILS listings, Highland pages, and local citations.
8. Ask residents for reviews through Highland's approved review process; do not reuse old review widgets unless ownership and accuracy are confirmed.
9. Track Search Console queries for branded, local, floor plan, pet-friendly, amenity, and neighborhood searches.

## AEO content rules

- Put the direct answer near the top of each page.
- Keep answers factual and specific: address, neighborhood, floor plan types, amenities, pet-friendly status, contact details, and application destination.
- Do not make claims that change often, such as exact rent, concessions, unit counts, or availability, unless those claims come from the live Highland/AppFolio source.
- Use internal links with descriptive anchor text, such as `View Available Units`, `Apply Now`, `Schedule a Tour`, and `View Floor Plans`.
- Keep important content in visible text, not only images, scripts, embeds, or PDFs.
