# artifact.toml Rewrite & Build Pattern

The `artifact.toml` file (auto-managed by Replit's artifact system) drives two
things for the web artifact:

1. **Build command** — the full `pnpm run build` pipeline.
2. **URL rewrites** — clean-URL routing so `/amenities` serves the prerendered
   `dist/public/amenities/index.html` without a platform 301 through a slash.

The production server (`server/index.mjs`) parses this same rewrite table at
startup, so it and the platform use a single source of truth.

---

## Build command pattern

```toml
[services.production]
  build = "pnpm --filter @workspace/YOUR-ARTIFACT-NAME run build"
  run   = "pnpm --filter @workspace/YOUR-ARTIFACT-NAME run preview"
```

---

## Rewrite pattern

Every page needs two entries:
- The clean URL → the prerendered `index.html`
- A trailing-slash variant that the production server turns into a 301

```toml
# ── Static pages ─────────────────────────────────────────────────────────────
[[services.production.rewrites]]
from = "/amenities"
to   = "/amenities/index.html"

# (no trailing-slash entry needed — server/index.mjs handles those universally)

# ── Per-unit dynamic pages ────────────────────────────────────────────────────
# One pair per unit in UNIT_PATHS from entry-server.tsx.
# generate-unit-rewrites.mjs writes these automatically into a managed region
# of artifact.toml; do not hand-edit between the generator markers.

# [UNIT REWRITES START — managed by generate-unit-rewrites.mjs]
[[services.production.rewrites]]
from = "/available-units/0101"
to   = "/available-units/0101/index.html"

[[services.production.rewrites]]
from = "/available-units/0202"
to   = "/available-units/0202/index.html"
# [UNIT REWRITES END]

# ── Knowledge / Floor-plan / Blog pages ──────────────────────────────────────
# Same pattern: one rewrite per slug.
[[services.production.rewrites]]
from = "/knowledge/how-to-apply"
to   = "/knowledge/how-to-apply/index.html"
```

---

## Key rules

- **Rewrites are exact-match, non-wildcard.** Every clean URL path that can
  be prerendered needs its own `from`/`to` pair.
- **Trailing-slash 301s** are handled universally by `server/index.mjs` (it
  strips the trailing slash and redirects). You do not need rewrite entries for
  `/amenities/` → `/amenities`.
- **Per-unit rewrites** are auto-generated by `generate-unit-rewrites.mjs`.
  Run `pnpm run generate:unit-rewrites` whenever a new unit is added to
  `UNIT_PATHS` in `entry-server.tsx`.
- **The production server must stay in sync.** `server/index.mjs` reads
  `artifact.toml` at startup. If you add a page to the rewrite table, the
  server will serve it correctly on next deploy without any code change.
