---
name: Launcher validation in clean Replit apps
description: How launcher neutrality validation should treat Replit-generated runtime files after ZIP import.
---

Launcher neutrality scanners must ignore known top-level runtime directories generated by Replit
and Node tooling, while continuing to strictly allowlist every launcher-owned file.

**Why:** A clean ZIP import can create runtime directories such as `.config` before validation.
Filesystem entries may also be non-regular files. Recursively reading every entry as UTF-8 causes
`EISDIR` failures even though the launcher payload itself is valid.

**How to apply:** Traverse regular files only, reject unsupported launcher filesystem entries, and
exclude only narrowly named top-level runtime directories. Always test in an isolated copy that
simulates Replit's generated directories.
