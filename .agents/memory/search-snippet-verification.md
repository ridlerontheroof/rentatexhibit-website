---
name: Search snippet verification
description: How to distinguish an unindexed page from a query-dependent or rewritten Google snippet.
---

An exact-phrase Startpage search returning no results does not prove the page is absent from Google's index. Confirm with canonical-URL and exact-title probes, then compare the returned snippet with both the meta description and the opening body copy.

**Why:** Google-backed results can expose an indexed page for a title or canonical probe while omitting it for a quoted description. Google may also select the opening paragraph instead of the meta description.

**How to apply:** For snippet audits, use at least two query shapes per page. If Google repeatedly chooses body text, put the curated fact-first description at the beginning of the visible page copy so either source yields the intended facts.
